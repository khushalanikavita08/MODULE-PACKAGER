# MODULE-PACKAGER

🧰⚡ Multi-Utility Toolkit
"One toolkit, endless utilities — because every developer deserves a Swiss Army knife in Python."

A powerful, menu-driven Python command-line application that bundles together everyday utility operations — date & time tools, math operations, random data generation, unique ID creation, and file handling — all in one simple, interactive toolkit.

📖 Meaning of the Project
In daily programming and scripting work, we often need small standalone utilities — checking the current time, calculating date differences, generating a random password, creating a UUID, or reading/writing files.

Instead of writing separate scripts for each of these, the Multi-Utility Toolkit brings them all together under a single, easy-to-navigate console menu.

🧭 Project Overview
Built entirely using Python's standard library (datetime, time, math, random, uuid) along with two custom modules (file_operations and math_operations), the toolkit offers a clean, menu-based navigation system for beginners and developers alike.

✨ Key Features
⏰ Live Date & Time Display — Instantly view the current system date and time
📅 Date Difference Calculator — Find the number of days between two given dates
⏳ Countdown Timer — Run a live countdown for any given number of seconds
🔐 Random Password Generator — Build strong, custom-length passwords
🆔 UUID Generator — Create globally unique identifiers
🧮 Mathematical Operations — Factorial, Compound Interest, Trigonometry & Area calculations
📂 File Operations — Create, write, read, and append files with ease
🔍 Explore Module Attributes — Inspect built-in Python module attributes live using dir()
🔁 Fully Menu-Driven Navigation — Smooth back-and-forth flow between all sub-menus
🎯 Uses
🧑‍💻 Learning Python — A beginner-friendly way to explore modules like datetime, math, random, and uuid
🛠️ Quick Utility Access — Perform common tasks (date calculations, passwords, UUIDs) without writing separate scripts
🧮 On-the-Go Calculations — Factorial, compound interest, trigonometry, and area calculations from the command line
📂 Basic File Handling — Create, read, write, and append text files directly from the CLI

🚀 How to Run
Clone or download this repository
bash
git clone https://github.com/<your-username>/Multi-Utility-Toolkit.git
cd Multi-Utility-Toolkit
Make sure Python 3.x is installed on your system
Run the following command:
bash
python main.py
Follow the on-screen menu to choose the operation you want to perform
